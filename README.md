# Citas Tattoo

Aplicación web de reservas para **Tuétano Tattoo Space** (Elche). Proyecto Intermodular, 2º CFGS DAW, IES Severo Ochoa.

## Problema
El estudio gestiona hoy sus citas a mano por Instagram, WhatsApp y teléfono.

## Funcionalidades previstas
- Registro e inicio de sesión con tres roles: cliente, tatuador y administrador.
- Gestión de tatuadores, servicios y horarios.
- Consulta de huecos libres y reserva de citas sin solapamientos.
- Diseño responsive.

## Tecnología
HTML, CSS y JavaScript (módulos ES) · Supabase · Netlify · GitHub.
